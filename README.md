# 🏫 Sistema de Inscrição Online - Escola 30 de Setembro  

Este projeto é o **frontend** do sistema de inscrição online da **Escola 30 de Setembro**, permitindo que candidatos realizem suas inscrições e enviem documentos de forma digital. O sistema também conta com uma interface para avaliadores analisarem inscrições e um painel administrativo para gestão do processo.  

---

## 📌 Funcionalidades  

✔️ **Autenticação** → Login e recuperação de senha.  
✔️ **Cadastro de Candidatos** → Formulário de inscrição online.  
✔️ **Upload de Documentos** → Envio de BI, certificados e outros arquivos necessários.  
✔️ **Acompanhamento da Inscrição** → Candidatos podem verificar o status da candidatura.  
✔️ **Área do Avaliador** → Interface para análise, aprovação e rejeição de inscrições.  
✔️ **Painel Administrativo** → Gestão de usuários, inscrições e configurações.  
✔️ **Design Responsivo** → Interface otimizada para desktop e mobile.

## 🛠️ Como Executar o Projeto  

1️⃣ **Clone o repositório**:  
```sh
git clone -b frontend https://github.com/OrlandoMartinho/Sistema-de-inscricao-do-30-de-Setembro.git
```

2️⃣ **Acesse a pasta do projeto**:  
```sh
cd Sistema-de-inscricao-do-30-de-Setembro
```

3️⃣ **Abra o arquivo `index.html` no navegador**:  
- No **Windows**:  
```sh
start index.html
```  
- No **Linux**:  
```sh
xdg-open index.html
```
- No **MacOS**:  
```sh
open index.html
```
