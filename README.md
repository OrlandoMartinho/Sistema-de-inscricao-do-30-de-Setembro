# README - Protótipo do Sistema de Inscrição do 30 de Setembro

## Visão Geral
O protótipo do "Sistema de Inscrição do 30 de Setembro" foi desenvolvido para representar visualmente a interface e o fluxo de navegação do sistema. Ele permite validar a experiência do usuário (UX) antes da implementação final. O protótipo foi criado utilizando o **Adobe XD** e segue as diretrizes estabelecidas no diagrama de caso de uso.

## Objetivo do Protótipo
- Demonstrar a interface gráfica e interação dos usuários com o sistema.
- Validar o fluxo de navegação e a usabilidade antes do desenvolvimento completo.
- Obter feedback de stakeholders e ajustar possíveis melhorias.

## Ferramentas Utilizadas
- **Adobe XD** para design da interface.
- **StarUML** para modelagem de casos de uso.

## Funcionalidades Simuladas no Protótipo
O protótipo inclui telas interativas que representam as principais funcionalidades do sistema:

### Para o Candidato:
1. Tela inicial com informações sobre a plataforma.
2. Tela de **Login e Cadastro**.
3. Interface para **Submissão de candidatura**.
4. Tela de **Gerenciamento de inscrições**, incluindo edição, cancelamento e acompanhamento do processo.
5. **Configurações da conta**, como alteração de dados e credenciais.

### Para o Administrador:
1. **Dashboard** com visão geral do sistema.
2. **Gestão de funcionários**, permitindo cadastrar, editar e remover funcionários.
3. **Supervisão de inscrições**, incluindo comentários e relatórios.
4. **Visualização de gráficos e status do sistema**.
5. **Configurações do sistema**.

### Para o Avaliador:
1. Tela de **Gestão de inscrições**.
2. Opções para **aprovar ou reprovar inscrições**.

## Fluxo de Navegação
- O usuário acessa a **página inicial** e pode visualizar informações sobre o sistema.
- Para interagir com o sistema, o usuário deve realizar o **login ou cadastro**.
- Dependendo do perfil (Candidato, Administrador ou Avaliador), diferentes funcionalidades são apresentadas.
- Todas as ações são representadas de forma interativa no protótipo, permitindo simular a experiência do usuário final.


## Conclusão
O protótipo do "Sistema de Inscrição do 30 de Setembro" é uma representação visual essencial para garantir que o sistema final atenda às necessidades dos usuários e funcione conforme esperado. Com esse modelo, é possível validar e refinar a interface antes da implementação completa.
